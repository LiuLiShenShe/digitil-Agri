## Context

PRD 判断资产数量不应掩盖质量问题。多保真资产池需要服务业务目的：关键真实植株使用 F2DMAS 或高保真重建，普通缺失资产使用 TRELLIS.2，规则几何使用程序化生成，已有资产优先复用，无法立即补齐时使用占位模型不中断场景搭建。

## Goals / Non-Goals

**Goals:**

- 定义统一资产元数据和质量验收规则。
- 支持资产保真度路由和选择理由输出。
- 支持关键植株阶段性几何版本。
- 支持缺失资产以占位模型继续场景生成，并创建生成任务。
- 支持 ValidatorAgent 识别缺缩略图、缺来源、缺许可和缺质量信息。

**Non-Goals:**

- 不要求所有历史资产一次性补齐完整元数据。
- 不将 TRELLIS.2 作为关键植株表型测量可信几何来源。
- 不做每日植株 GLB 重建。
- 不在本变更中完成 F2DMAS 训练或采集规范。

## Decisions

- 资产必须有 `assetKey` 作为稳定引用，避免 GLB 路径变更导致场景失效。
- 元数据分为基础信息、质量信息、许可来源、适用对象、版本和保真度。
- 路由策略按对象类型、业务价值、是否关键样本、等待时间和可用资产决定。
- 缺失资产使用占位模型保证场景可加载，同时创建 `asset.job.create` 任务记录需求。
- 关键植株几何版本按苗期、营养生长期、开花期、结果期、成熟期等 milestone 管理。

## Risks / Trade-offs

- 资产治理工作量大，因此验收指标先设为公开 GLB 基础元数据完整率不低于 80%。
- 高保真重建耗时高，必须只用于关键植株、异常植株和论文样本。
- 程序化生成适合地块、道路、围栏、沟渠、管线，但不应冒充真实高保真资产。
